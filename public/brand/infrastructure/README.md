Vendor artwork is used to identify the deployed services. Original assets and source URLs are recorded in sources.json. The client browser icon is an original interface symbol; the portfolio mark uses the existing Ataimo identity. Logos retain their original colors and proportions on raised 3D badges.

Delivery logos are sourced from Simple Icons and rendered in the platform’s evergreen delivery color. GitHub, Actions, Docker, Terraform, Ansible and Helm identify external delivery tooling, not services running inside the VM.
