# Ataimo Edem portfolio

An engineering portfolio for enterprise clients, collaborators and hiring teams. Ataimo is a Customer Success Engineer at Tyk, working across EMEA on API platforms, architecture, migrations and production troubleshooting. The work combines technical depth and customer ownership.

The site must help visitors understand the engineering approach, inspect real case studies, and contact Ataimo. Source content and project disclosures live in content/site.ts. Preserve all routes, contact validation, repository links, resume download and accessibility.

The user requests a full visual rebrand at DisciteX-level craft: connected content scenes, interactive background, live texture and native entry motion. The user rejected an overall dark theme. Use a professional light color identity. Native browser animation only, no GSAP or Framer Motion; retain reduced-motion and WebGL fallbacks. Never invent customer logos, outcomes or metrics. Consultancy and SSO now extend the site through the locally deployed client portal.

The local Kubernetes client portal is now implemented: branded account registration and login backed by Keycloak, consultation request-and-approval scheduling, client engagements, private job conversations and public measured local workload status. `/portal` and `/status` extend the approved identity. Public portfolio viewing remains anonymous; clients can register, and owner privileges require explicit provisioning. This is local Kind functionality, not a production/cloud deployment.
