# SKILL PROFILE: BRAND-GUIDELINE

- **Isolation Protocol**: Enforce standard design variables. Never generate hardcoded styling utilities like `pt-[11px]` or `bg-[#0a0a0a]`.
- **Theme Matching**: Map layout structures explicitly to our Tailwind 4 CSS custom theme properties (`var(--color-brand-bg)`, `var(--color-brand-border)`).
