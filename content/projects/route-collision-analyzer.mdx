## From investigation to diagnostic workflow

Duplicate or conflicting routes are a recurring API troubleshooting scenario. Domain and listen-path combinations provide the basis for detecting potential conflicts across APIs.

## What the tool does

- Retrieves API configuration using the Tyk Dashboard REST API.
- Analyses domain and listen-path combinations.
- Supports strict and broad match modes and internal API handling.
- Produces table, JSON and CSV output.
- Exposes CI-friendly exit codes for automated checks.

## Operational value

A repeatable CLI makes the investigation usable beyond a single support session. Human-readable tables suit diagnosis; structured output suits reporting and CI pipelines. Consult the repository for actual command flags and mode behaviour.
